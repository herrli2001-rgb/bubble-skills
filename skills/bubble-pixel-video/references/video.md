# 前20秒的视觉与动效方法

## 场景与人物

本参考是侧面偏俯视的室内像素短片，不是后半段草原路网图解。先定演员站位和脸部留白，再画房间。客厅中心主角脚部约逻辑 `(320,242)`，父母在两侧 `(215,225)/(430,225)`；宿舍主角约 `(320,246)`；办公室中心留出 `x275..430,y165..265` 的人物活动区。新场景可改变布局，但应保留中央叙事空间和下方字幕区。

房间由墙面、窗景、地板、灯、书架、植物、桌椅等构成；静态材质纹理使用坐标hash。窗外风景裁切在窗框内。脸部、手部和气泡前不放灯光锥或家具。文件和电脑上只画抽象标记，可读文字放在独立字体层，避免换主题留下旧文案。

同一主人公保留棕发、头部轮廓、领口等识别特征，可按主题改变服装、年龄和道具。角色比例通常1.35–1.6；情绪重点角色可约1.7。动作采用眨眼、眉毛、低头、扶额、抱物、指向、擦泪；脚部锚点固定。站位静止时不要用循环上下跳动制造“生动”。

源文件：`assets/starter/src/intro/actors.ts`、`living.ts`、`dorm.ts`、`office.ts`。`bedroom.ts`是备用房间，不默认插入片头。

## 稳定像素

- 逻辑640×360，输出1920×1080，固定相机 `{zoom:1,x:320,y:180}`。
- 双层Canvas都设 `imageSmoothingEnabled=false`，CSS设 `imageRendering:'pixelated'`。
- 绘制坐标取整。原生像素美术不用连续亚像素缩放；仅道具遮罩和短促UI入场可以有局部变换。
- 背景纹理不得每帧 `Math.random()`。窗帘、时钟、指示灯可以局部微动，但不移动整张房间或整个人物来代替情绪。

## 信息层级

以下数值为1080P参考，改长文本时重新量宽、断行。

| 元素 | 参考参数 |
|---|---|
| 年龄/阶段 | 左75、上52；72px，地点30px |
| 底部旁白 | 左右各100、距底60；60px，行高78px，两行 |
| 主要气泡 | 48px，行高60px；小气泡36/48px |
| 气泡边框/阴影 | 6px边框，6–9px硬阴影 |
| 字体 | 本地 Fusion Pixel 12px 简体，保留许可证 |

人物层与心声层在中间，底部字幕实际可能上伸至输出y≈864，布局按真实文本框检查。`whiteSpace:nowrap` 不会替你折行，必须主动给 `lines`。气泡不遮脸，不占年龄标签，不挤入字幕。

## 压力与哭泣

压力来自积累，不是抖屏。参考父母8句源帧34/50/68/84/100/116/132/148，在1.5倍播放下约每0.36–0.40秒加一句。亲戚6句源帧30/58/86/114/142/170，约0.62秒加一句。旧句保留，新句从两侧逐渐包围主角；奶油色逐步变为暖橙、暗红框，中心仍留白。

父母气泡仅短促 `scale 0.96→1` 后固定；亲戚气泡从左右移入18px后固定。气泡密度、句数和内容按新主题决定，不能默认所有情节都被斥责。

哭泣分阶段：委屈→红眼→两侧泪线→独立泪滴→缓慢擦泪。保留深色瞳孔和面部，不用蓝白矩形盖住整张脸；手仅触碰对应脸侧。只对该场景角色开启哭泣，不改变共享角色导致全片一起哭。

## 变速只有一个时钟

`sourceFrame = useCurrentFrame() * playbackRate` 同时驱动人物、房间微动、气泡、字幕。源时间事件和输出时间不能混用。

案例四段源长度294/294/294/300帧，速度1.5/2.1/2.1/1.5，输出196/140/140/200帧，扣除三个16帧转场得到628帧，约20.93秒。这是案例节奏，不是每个新主题的固定规格。

新主题按阅读和动作安排长度。用户要求“当前再快1.4倍”时将既有速度乘1.4，并相应缩短输出；不要把原先已1.5倍误认为1倍。只改指定段，不为总时长擅自拉慢其它段。未给总时长不硬凑90秒。

## 道具转场

模板含试卷、屏幕、纸箱以及备用门板，参考时长16帧/30fps≈0.53秒。前半段道具靠近并遮满画面；p=0.5时换场；后半段道具离开揭示新场。遮罩只在 entering 层绘制，避免双重遮挡。

换主题时替换道具及发起位置。例如简历连接求职、电脑连接办公、行李连接搬家。不要让凭空出现的试卷承接不相关剧情。检查过渡中点全屏覆盖、前后露底、人物和旧字幕是否被切点闪现。

## 音频

新主题指定BGM时单独取得并记录来源；原案例的第三方音轨不包含在skill里，也不是新项目的默认授权素材。没指定时可调用 `scripts/make-original-audio.py` 生成轻柔原创音轨，或创作更适合主题的音乐。默认只用BGM与轻微拟音，不自动加旁白。场景速度改变后移动/压缩拟音，音乐通常保持原速原调，首尾做淡入淡出。
