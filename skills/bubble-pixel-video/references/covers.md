# 横竖封面：大字、小人、独立构图

先看 `assets/reference/landscape.png` 和 `portrait.png`，复用信息层级与像素语言，标题替换为新主题。默认输出两张静态PNG，不进入视频时间线。

| 项目 | 横封面 | 竖封面 |
|---|---|---|
| 成品 | 1920×1080 | 1080×1920 |
| 逻辑画布 | 640×360 | 360×640 |
| 放大 | 整数3倍 | 整数3倍 |
| 思考框逻辑矩形 | `(56,28,528,200)` | `(16,90,328,240)` |
| 主角脚部逻辑坐标 | `(320,316)` | `(180,490)` |
| 主角尺寸 | 约21×40逻辑像素 | 约21×40逻辑像素 |
| 参考两行字号 | 192/204px | 144/156px |
| 参考行高 | 246px | 192/204px |

标题是第一焦点，小人物提供情绪。参考标题为6字+5字；新标题先按语义重新断行，必要时用三行并重新计算框高、圆点位置。字体优先12px的整数倍，不横向压扁字形。当前横版文本容器宽1584px、竖版984px；边框内再留空，不能按容器宽把字顶到边上。

默认配色：森林绿背景 `#173c36`、奶油纸 `#f1e4b9`、深绿边框 `#395443`、旧金边 `#b5a476`、主标题 `#365344`、暖棕强调 `#a46c3c`。框是阶梯像素角，阴影是硬边色块。标题下的三颗思考点递减，最后一点不碰头，人物一手扶下巴。

横版背景冻结在一个世界帧，原实现 `drawWorld(c,90)`；不要让羊、水面、纹理或角色随海报帧随机变化。竖版重新生成纵向河流、树、屋、脚下小路，阅读顺序是标题→思考点→人物→环境，不能从横版裁切或拉伸。

模板文字集中在 `src/project.json` 的 `landscapeTitleLines` / `portraitTitleLines`；两图可分别断行。更长标题或不同情绪姿态时修改 `Cover.tsx` 与 `PortraitCover.tsx` 对应位置。保留小人物尺寸比例，不把人物扩大为海报主体。

代码依赖要齐：横封面 `Cover.tsx` 使用 `world.ts`；竖封面从 `Cover.tsx` 导入绘图原语和专用人物；字体和许可证也需一起复制。不要只拷两张组件文件后仍依赖原聊天工程。

分别渲染原尺寸及缩略图，确认：完整标题一眼可读、无自动缺字/挤字、人物未裁切、头与思考点分离、同主题同角色同色系、竖图确为独立排版。
