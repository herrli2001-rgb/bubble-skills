# 来源与公开版范围

工作方法参考 Eian（@EianLu）的《Claude code/Codex+Seedance AI视频：从一个想法到成片的全流程》，由用户提供的文章滚屏视频整理。公开包保留方法出处，不包含来源视频、文章全文、原作者的十段完整提示词或原文截图。

本技能由 bubble lxp 维护。公开版包含重新组织的制作与审核流程、当前宿主的工具适配，以及本地首尾帧检查、任务请求准备、单次提交、状态查询、下载和抽帧辅助脚本。不将这些方法说明等同于对原文、Seedance 服务或其他第三方素材的所有权。

当前助手可以担任导演，不要求嵌套启动其他模型。用户已选画风、素材、规格和预算优先；四角色协作仅在当前任务允许多 agent 时启用。

API 格式参考火山方舟官方文档：

- [创建视频生成任务](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)
- [视频生成教程](https://console.volcengine.com/ark/region%3Acn-beijing/docs/video-generation-tutorial)

模型与接入点 ID、账户权限、价格、分辨率和时长限制须在实际制作时核对。离线测试只验证本地处理和模拟请求，不证明实际账户的付费生成已经可用。
